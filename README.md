# ASTRA 🪐

### Uma jornada interativa em 3D pelo universo.

🌌 **[✨ EXPLORAR O ASTRA — ACESSE AQUI](https://astra-henna-delta.vercel.app/)**

Explore o Sistema Solar, descubra corpos celestes e viaje pelas regiões do espaço profundo em uma experiência interativa em 3D, diretamente pelo navegador. Não é necessário instalar nada para acessar a versão online!

---

## ✨ Funcionalidades

- **Sistema Solar em 3D:** explore planetas e outros corpos celestes.
- **Planetas procedurais:** descubra superfícies planetárias geradas por shaders.
- **Exploração do espaço profundo:** conheça galáxias, nebulosas, estrelas e buracos negros.
- **Navegação interativa:** viaje pelo universo e observe diferentes objetos celestes.
- **Efeitos visuais imersivos:** explore atmosferas, anéis planetários, iluminação e cenários espaciais.

## 🛠️ Tecnologias utilizadas

- React
- TypeScript
- Vite
- Three.js
- React Three Fiber
- Shaders WebGL (GLSL)

## 🚀 Como executar o projeto localmente

Se quiser baixar o código e executar o ASTRA no seu próprio computador, você precisará ter o [Node.js](https://nodejs.org/) e o npm instalados.

**1. Clone este repositório:**

```bash
git clone https://github.com/JuliaFreireSoubhia/ASTRA.git
```

**2. Entre na pasta do projeto:**

```bash
cd ASTRA
```

**3. Instale as dependências:**

```bash
npm install
```

**4. Inicie o servidor de desenvolvimento:**

```bash
npm run dev
```

**5.** Abra no navegador o endereço local exibido no terminal.

## 🌌 Objetivo do projeto

O ASTRA é um projeto de portfólio voltado ao desenvolvimento web, à computação gráfica 3D e à exploração espacial. Seu objetivo é proporcionar uma experiência interativa e visualmente envolvente para descobrir o universo por meio da tecnologia.

## 📌 Status do projeto

O ASTRA está em desenvolvimento contínuo. Novas funcionalidades, melhorias visuais e ajustes nas simulações dos corpos celestes poderão ser adicionados ao longo do tempo.
